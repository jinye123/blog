# 关于

::: tip 一句话
AI 时代的前端面试与工程化指南。
:::

## 这个博客是什么

面向前端工程师的**面试 + 工程化 + AI** 知识库，专注：

- **高频考点**：每个知识点都对应面试官真实的追问
- **深度原理**：不只讲 API，讲底层
- **可落地实践**：项目实战 STAR 化，可直接讲给面试官
- **AI 差异化**：作为前端的差异化亮点
